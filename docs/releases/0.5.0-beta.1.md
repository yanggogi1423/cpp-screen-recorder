# FARecorder 0.5.0-beta.1

2026-10-29. Windows x64 portable beta.

- **GPU 직접 인코딩**: Windows D3D11 → GPU 색상/크기 변환 → Media Foundation 하드웨어 H.264. 작은 녹화 창에서는 앱의 CPU 픽셀 읽기를 제거한다.
- 캡처 콜백의 매 프레임 CPU 읽기를 지연 읽기로 변경. 기존 CPU·FFmpeg 인코더도 계속 선택할 수 있다.
- GPU 경로에서 기존 일시정지·영역 이동·오디오 트랙 결합·저장 흐름 유지
- **도움말 → 업데이트**: 시작 시 하루 한 번 확인, 안정/베타 채널, 다운로드·SHA256 검증, 준비 후 종료·교체·재실행
- 업데이트 실패 복구, 이전 버전 백업과 사용자 파일 보존, 녹화/미저장 상태 설치 차단
- macOS Metal/CoreImage/VideoToolbox 경로와 번들 업데이트 도우미 구현. 실제 Mac의 녹화·성능·앱 교체는 별도 검증 대상

GPU 직접 경로는 상세 패널의 인코더에서 선택합니다. 호환 GPU/드라이버가 필요하며 실제 사전 검사에 실패하면 CPU 인코더 등을 직접 선택해야 합니다.

0.4 버전에는 업데이트 기능이 없으므로 **이번 버전은 한 번 수동으로 압축 해제**해야 합니다. 이후 배포되는 버전부터 앱 내 업데이트를 사용할 수 있습니다. ZIP 전체를 풀고 FARecorder-Windows-x64/bin/FARecorder.exe를 실행하세요.

현재 공개 GitHub Releases를 사용해 별도 업데이트 서버 운영비가 없습니다. [업데이트 정책·배포 계약](../UPDATES.md), [검증 범위](../VALIDATION-0.5.md)를 참고하세요. Windows 패키지는 기존처럼 서명되지 않은 베타이며, 물리 Mac 검증 전이므로 이번 첨부 파일은 Windows용입니다. 원본 MIT 및 서드파티 라이선스는 유지합니다.
