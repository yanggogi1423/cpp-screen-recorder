# FARecorder 0.4.0-beta.3

2026-10-28. Windows x64 portable beta.

- 녹화별 하위 폴더 대신 선택한 저장 폴더에 영상을 직접 저장
- 녹화 시작 시간 기반 기본 파일명 (`2026-10-28_21-45-30-123.mp4`), 저장 창에서 이름·위치 변경
- 복구용 작업 데이터는 앱의 로컬 Recovery 경로로 분리, 파일 메뉴에 복구 파일 열기 추가
- 미저장 상태에서 종료하면 저장 후 종료 / 저장하지 않고 종료 / 취소 선택
- 저장 취소·실패 시 종료하지 않고 수정한 파일 이름·폴더 유지
- 미저장 녹화가 새 녹화·다른 파일 열기로 가려지지 않도록 보호

전체 무음 자동 검사 11개와 실제 Windows WGC 영역 녹화·편집·저장·종료 취소 검사를 통과했습니다. [검증 기록](../VALIDATION-0.4-beta.3.md).

ZIP 전체를 압축 해제하고 FARecorder-Windows-x64/bin/FARecorder.exe를 실행하세요. 서명되지 않은 Windows 베타입니다. 실제 Mac 검증 전으로 macOS 실행 파일은 첨부하지 않습니다. 원본 코드 MIT와 D2Coding OFL, Qt·FFmpeg 각 라이선스를 유지합니다.
