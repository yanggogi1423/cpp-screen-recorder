# FARecorder 0.5.0-beta.2

2026-10-31. Windows 베타 수정판.

- 녹화 종료 후 ‘저장 중’만 표시되던 문제를 수정했습니다. 녹화 종료 상태, 소리 입력 종료/영상 마무리/영상·소리 결합 단계, 실제 결합 진행률과 경과 시간을 표시합니다.
- 오디오 독립 트랙과 전체 믹스를 AAC로 만드는 작업이 오래 걸려도 계속 진행 중이면 완료까지 기다립니다. 이전에는 전체 결합 시간이 5분을 넘으면 진행 여부와 관계없이 중단했습니다.
- 실제 진행과 출력 파일 변경이 5분간 없을 때만 결합을 중단하며 복구 원본을 보존합니다. 결합 로그는 작업 도중에도 기록합니다.
- 진행률은 파일 정리가 성공적으로 끝난 뒤에만 100%가 됩니다. 이후 이름·폴더를 선택하는 기존 저장 창이 열립니다.

긴 녹화의 후처리 자체가 즉시 끝나는 것은 아닙니다. 이번 수정은 진행 상태 표시와 잘못된 전체 시간 제한을 해결합니다. Windows 무음 회귀 검사와 합성 영상·무음 오디오 2개 및 전체 믹스의 실제 인코딩/디코딩으로 확인합니다. 실제 macOS 장비 검증은 별도입니다.
