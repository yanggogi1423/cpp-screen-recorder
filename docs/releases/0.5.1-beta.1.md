# FARecorder 0.5.1-beta.1

2026-11-05. Windows 설치판 베타.

- `FARecorder-0.5.1-beta.1-windows-x64-Setup.exe`를 실행해 설치합니다. 관리자 권한 없이 현재 Windows 계정에 설치하며 시작 메뉴·설치된 앱·제거 프로그램을 제공합니다.
- 기존 ZIP 사용자는 설치 파일을 한 번 실행하면 기존 설정·녹화·복구 원본을 이어서 사용합니다.
- 새 버전을 시작 후 약 3초, 앱 활성화 시 및 실행 중 15분마다 확인합니다. 캐시 때문에 새 버전 알림이 사라지던 문제와 녹화 중 미뤄진 알림을 보강했습니다.
- ‘업데이트 시작’ 승인 후 다운로드·SHA256 검증·적용·자동 재실행까지 이어집니다. 작업 중인 녹화나 미저장 영상이 있으면 설치하지 않습니다.
- 제거·재설치 시 사용자 파일과 앱 데이터는 보존합니다. 잘못된 패키지, 다른 프로그램 폴더, 경로 이탈, 연결된 설치 경로를 거부합니다.

릴리즈의 ZIP은 내부 업데이트와 기존 0.5.0 클라이언트 호환용입니다. 일반 설치는 Setup.exe를 사용하세요. macOS 코드는 CI로 검사하며 실제 Mac 장비 검증 전까지 Mac 설치 파일은 공개하지 않습니다.
