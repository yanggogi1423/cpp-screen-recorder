# FARecorder 0.4.0-beta.2

2026-10-28. Windows x64 portable beta.

- 녹화 최적 화면의 타이머 외 빈 영역에서도 창 이동
- 최대화 버튼·제목 표시줄 이동 시 최대화 전 일반 창 크기로 복원
- 정지 후 편집기 대신 파일 이름·폴더를 지정하는 저장 창을 먼저 표시
- 저장 창에서 선택적으로 편집, 편집 닫기 후 저장으로 복귀
- 녹화 중 타이머 옆에 최종 영상의 예상 파일 크기 표시, 대기 타이머 숨김 및 초기화
- 새 파일 저장과 확인 후 덮어쓰기, 별도 작업 스레드에서 복사하며 실패 시 원본 보존
- README에서 개선 가능한 구현 제약, 공통 장비 조건, 캡처 단위, 미검증 범위를 구분

로컬 무음 자동 검사 11개, Windows 네이티브 창 검사, 실제 WGC 영역 녹화/이동·저장 흐름, 무음 편집 회귀 검사를 통과했습니다. [검증 기록](../VALIDATION-0.4-beta.2.md).

ZIP 전체를 압축 해제하고 FARecorder-Windows-x64/bin/FARecorder.exe를 실행하세요. 예상 크기는 RAM이나 세션 전체 점유량이 아니며 최종 파일과 차이가 날 수 있습니다. 세션 복구 원본은 유지됩니다.

Windows 패키지는 서명되지 않은 베타입니다. macOS는 CI 빌드·자동 검사 대상이며 물리 Mac 검증 전이므로 이번 릴리즈에 실행 파일을 첨부하지 않습니다. 원본 코드 MIT, D2Coding OFL, Qt·FFmpeg 각 라이선스를 유지합니다.
