# FARecorder 0.5.2-beta.1

2026-11-25. 복구 원본 자동 정리와 배포 용량 보강.

- 최종 영상 저장이 성공하면 해당 녹화의 Recovery 폴더를 자동 삭제합니다. 원본 영상, 독립 WAV, 중간 편집본과 로그가 계속 쌓이지 않습니다. 최종 영상의 독립 오디오 트랙은 유지합니다.
- 저장 취소·실패·덮어쓰기 미승인·미저장 상태에서는 복구 원본을 유지합니다. 파일 복사와 최종 반영이 완료된 뒤에만 정리합니다.
- 앱이 만든 복구 폴더임을 확인하고 해당 세션만 지웁니다. 소유 경로가 다르거나 링크가 있으면 보존하고 실제 오류를 표시합니다. 최종 영상 저장 위치로 임시 Recovery 폴더를 선택할 수 없습니다.
- 설치 패키지에서 중복 CRT 설치 EXE를 제외합니다. 앱 실행에 필요한 CRT DLL과 코덱은 포함합니다.
- 개발·검수 캐시 정리 스크립트와 무음 저장/복구 삭제 회귀 검사를 추가했습니다.

기존 버전에서 쌓인 미저장 복구본은 일괄 자동 삭제하지 않습니다. 이번 사용자 요청으로 이 PC의 기존 복구본은 별도로 삭제했습니다. 새 버전은 앞으로 최종 저장이 완료된 세션을 정리합니다.
