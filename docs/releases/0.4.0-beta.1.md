# FARecorder 0.4.0-beta.1

공개일: 2026-10-28. Windows x64 portable beta.

- 전체 화면·특정 창·영역 녹화, 영역의 원본 픽셀 크기 저장과 녹화 중 이동
- MP4 기본 저장과 저장 폴더 선택
- 프로그램·마이크·출력 장치별 오디오 선택 및 독립 트랙, 녹화 중 음량·음소거 조절
- 소리 테스트, 실제 인코더 검사, 일시정지·재개, Ctrl+R / Ctrl+P 단축키
- 기본/상세 패널과 작은 녹화 화면, 통합 상단바 및 자동 소스 목록 갱신
- D2Coding 1.4.0 내장, MIT 원본 코드와 별도 서드파티 라이선스 고지
- 녹화 후 자르기, 새 파일 저장·원본 덮어쓰기 선택

ZIP 전체를 압축 해제하고 `FARecorder-Windows-x64/bin/FARecorder.exe`를 실행합니다. 설치 프로그램과 관리자 권한은 필요하지 않습니다. SHA256 파일로 다운로드 파일의 무결성을 확인할 수 있습니다.

이 베타는 서명되지 않은 Windows 패키지입니다. macOS 빌드/자동 검사는 CI에서 확인하지만 물리 Mac의 실제 캡처·장치·권한·단축키 검증은 남아 있으며 이번 공개 첨부 파일에는 macOS 패키지를 포함하지 않습니다. 고해상도·고FPS·장시간 녹화의 성능은 장비에 따라 달라집니다.

검증 범위는 [0.4 검증 기록](../VALIDATION-0.4.md)을 참고하세요. MIT는 FARecorder 원본 소스에 적용하며 D2Coding(OFL), Qt, FFmpeg는 각 기존 라이선스를 유지합니다.
