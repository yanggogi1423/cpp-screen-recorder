# 0.5.1-beta.1 설치·업데이트 검증

2026-11-05. Windows11 / Qt6.8.3 / MSVC / 공식 NSIS3.13.

Game Test Launcher 세션과 해당 프로젝트의 설치·업데이트 구현을 참고했다. FARecorder는 사용자별 Setup 배포, 시작 메뉴·제거 등록, 승인 후 진행·재실행 흐름을 적용하고 기존 검증된 ZIP 트랜잭션 업데이트를 유지한다. 녹화 중 및 미저장 상태의 보호를 우선한다. 다른 프로젝트의 인증·서버·오프라인 접속 정책은 이 오프라인 녹화 앱에 적용하지 않는다.

## 검증 경계

- 캐시된 새 버전을 재실행에서도 알리는지, 바쁜 상태에서 설치하지 않는지, 작업 후 알림을 다시 보내는지 네트워크 없이 검사한다.
- 기존 체크섬/경로 이탈/실패 복구/사용자 파일 충돌/취소/실제 부모 프로세스 검사를 유지한다. Windows에서 최초 설치·복구 설치·다른 폴더 거부·제거 전 잘못된 manifest 거부·사용자 파일 보존·재설치를 추가한다.
- 실제 NSIS 테스트 설치판은 고정된 시험 레지스트리와 시작 메뉴 이름을 사용하며 모든 설치 파일은 작업공간의 고유 폴더에 둔다. 실제 설치·복구·네이티브 UI·제거·재설치 뒤 사용자 영상/합성 설정 바이트와 등록 상태를 비교한다.
- 설치 프로그램은 공식 고정 ZIP의 크기·SHA256과 전체 추출 파일을 대조한 NSIS만 실행한다. 별도 전역 도구 설치는 없다. Qt/FFmpeg/D2Coding/NSIS 고지를 포함한다.
- 기존 로컬 휴대용 배포 폴더는 새 설치본 확인 후 작업공간 보관 경로로 이동한다. 녹화 원본을 삭제하지 않는다.

물리 Mac 캡처/설치·제거는 Windows 검사나 macOS CI 결과로 대신하지 않는다. 코드 서명·Apple 공증은 별도다.

## 로컬 결과

- CTest 16/16 통과. 업데이트 도우미의 최초 설치·복구·제거·재설치를 포함한 14개 트랜잭션 사례를 확인했다.
- 실제 112MB NSIS 시험 설치판으로 한글·공백·`&`를 포함한 경로에 최초 설치, 복구 설치, 네이티브 UI 실행, 제거, 사용자 데이터가 남은 폴더에 재설치 및 최종 제거를 모두 통과했다. 별도 HKCU 시험 등록과 시작 메뉴를 확인하고 최종 제거했다.
- Qt 라이선스 원문과 NSIS COPY­ING, 앱 로컬 Microsoft CRT DLL을 배포에 포함한다. 패키징 도구에서 숫자 버전 디렉터리만 선택하고 NSIS의 파일 인수를 Windows 절대 경로로 정규화한다.
