# Feature audit — 2026-10-27

첫 C++ 기반 버전의 빌드와 실행 테스트를 마무리한 뒤, 구현과 실측 결과를 구분해서 채웁니다. 경쟁 제품 비교는 공식 기능 문서와 현재 제공 상태를 근거로 기록합니다.

## 판정 기준

- 구현: 호출 가능한 실제 코드 경로가 존재함.
- 검증: 명시한 OS·조건에서 파일/음성/동작을 확인함.
- 미지원: 계획만 있거나 현재 코드 경로가 없음.
- 다른 OS에서 빌드 성공은 실제 화면·오디오 캡처 성공과 다름.

## 보강 대상 후보

1. 앱+시스템 오디오 중복 방지와 일반 플레이어용 믹스다운 트랙.
2. OS 믹서와 녹화용 믹서의 관계를 실측하고 명확하게 표시.
3. 일시정지/재개, 전역 단축키, 녹화 중 작은 컨트롤 바.
4. 인코더 가용성 사전 검사, 성능/누락 프레임/클리핑/디스크 잔량 안내.
5. 녹화 후 원본 보관·삭제 정책, 파일 증가량과 실패 복구 UX.
6. macOS 권한과 장치 변경, 서명/공증 및 실제 기기 테스트.

현재 표는 테스트 결과와 공식 비교 조사 후 갱신합니다.
