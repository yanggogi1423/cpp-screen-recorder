# Feature audit — 2026-10-27

첫 C++ 기반 버전의 구현과 실측 결과를 구분합니다. 상용 제품 비교는 아래 공식 자료에서 확인한 기능을 기준으로 했으며, 모든 제품·요금제에 같은 기능이 있다는 의미는 아닙니다.

## 판정 기준

- 구현: 호출 가능한 실제 코드 경로가 존재함.
- 검증: 명시한 OS·조건에서 파일/음성/동작을 확인함.
- 미지원: 계획만 있거나 현재 코드 경로가 없음.
- 다른 OS에서 빌드 성공은 실제 화면·오디오 캡처 성공과 다름.

## 현재 기능 목록

| 기능 | 구현 | 검증과 한계 |
|---|---|---|
| C++20 + Qt 6 / QML 공용 앱 | 완료 | 로컬 Windows 및 Windows/macOS CI 빌드·자동 테스트·배포 통과. 물리 Mac 캡처는 미검증 |
| 전체 화면 / 특정 창 | 완료 | Windows에서 앱 자신의 보이는 창을 WGC로 녹화 확인. 전체 디스플레이 수동 인수 검증은 남음 |
| 드래그 영역 지정 | 완료 | 논리 좌표→픽셀 변환 구현. 혼합 DPI·다중 모니터 수동 인수 검증 필요 |
| 해상도·FPS 직접 입력 | 완료 | 640×360, 30 FPS, 약 150 프레임/5초 파일 실측. 움직이는 프레임 150개 해시로 갱신 확인. 4K·120/240 FPS 성능 보장은 아님 |
| CPU / NVIDIA / Intel / AMD / Apple 인코더 | 경로 구현 | CPU H.264 실측. GPU별 장비/드라이버 시험 필요. 잘못된 GPU 선택은 오류로 보고 |

## 다음 보강 순서

**P0:** 녹화 전 소리 테스트와 소스 상태, 인코더 가용성 검사, 성능/디스크 계측, OS 믹서 관계 실측, Windows/macOS 기본 인수 시험.

**P1:** 일시정지·재개, 전역 단축키·작은 컨트롤 바, 자동 종료 타이머, 녹화 목록·원본 보관 정책, 큰 파일 편집 저장의 UI 응답성.

**P2:** 웹캠/PIP, 화면 주석·클릭 강조, 줌·추가 편집 기능. 초기에는 전사·AI 효과·클라우드 계정 기능을 넣기보다 안정적인 화면/소리 녹화 경험에 집중하는 것이 적절합니다.

## 검증 증거

Windows 11 build 26200, MSVC 19.38, Qt 6.8.3, FFmpeg 9.0.2에서 수행했습니다. CI 빌드와 물리 장비 검증을 혼동하지 않습니다.

- `artifacts/capture-result.json`: 실제 WGC 창 캡처 + 두 프로세스 오디오 녹화 결과.
- `artifacts/audio-verification.json`: 주파수 분리, 50% gain, mute/unmute의 PCM 실측.
- `artifacts/edit-result.json`, ffprobe: 영상 자르기/트랙 수, 새 파일 원본 보존/복사본 덮어쓰기 확인.
- `ctest`: 설정 검증, 인코더 인자, 실시간 gain/mute/clipping, RF64 헤더, 타임스탬프 간격/중복/무음, QML 로드.

생성된 미디어·로그는 Git에 포함하지 않습니다. 보호된 영상/DRM, 게임 후킹, HDR, 긴 연속 녹화, 혼합 DPI, 장치 분리·재연결, 절전 복귀, 디스크 가득 참은 아직 통과로 판정하지 않습니다.
