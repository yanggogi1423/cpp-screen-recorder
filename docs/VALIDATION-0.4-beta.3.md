# 0.4.0-beta.3 저장과 종료 흐름 검증

2026-10-28. Windows11 / Qt6.8.3 / MSVC19.38 / FFmpeg9.0.2. 기본 검사는 모두 무음이다.

## 구현

최종 MP4/MKV는 선택 폴더 바로 아래에 저장한다. 녹화 시작의 로컬 시각을 밀리초까지 기본 파일명으로 사용하고 저장 창에서 변경할 수 있다. 원본 영상·WAV·로그·미확정 작업 영상은 앱 전용 로컬 데이터의 Recovery에 둔다. 해당 경로는 파일 메뉴에서 열 수 있다. 기존 사용자 녹화 폴더나 파일을 이동·삭제하지 않는다.

Controller가 미저장 상태를 따로 관리한다. 녹화 완료에서 설정하고 성공적으로 저장한 경우에만 해제한다. 저장 창 닫기나 나중에는 해제하지 않는다. 미저장 녹화가 있으면 새 녹화나 다른 파일 열기로 기존 파일 참조를 바꾸지 않는다. 명시적으로 저장하지 않고 종료해도 내부 복구 데이터는 보존한다.

창 닫기는 미저장 시 세 선택지를 제시한다. 저장 후 종료는 파일 복사 성공 신호까지 기다리고, 저장 취소·실패는 종료를 취소한다. 녹화 중 종료도 먼저 녹화를 마친 뒤 이름·위치를 확정하게 하며 idle 전환만으로 종료하지 않는다. 같은 녹화를 다시 열 때 입력한 이름·위치를 유지한다.

## 검증 결과

로컬 자동 검사 11/11과 아래 실제 Windows 무음 경로를 통과했다. 결과는 artifacts/region-result.json에 기록하며 미디어·로그는 저장소에 포함하지 않는다.

- CTest 11개: 기존 코어·UI·창 복원·목록·마이그레이션·인코더 검사.
- 무음 실제 WGC 테스트: 시작 시각 파일명 파싱, 저장 창 기본 폴더 확인, 미저장 상태로 close()가 차단되는지, 종료 취소 후 창·영상 유지, 저장 후 종료를 선택해도 즉시 종료되지 않는지, 해당 저장을 취소하면 종료 의도가 해제되는지, 입력 이름 유지, 다른 녹화 시작이 이전 미저장 영상을 가리지 않는지 확인한다.
- 실제 편집기를 열고 닫은 뒤 사용자 이름으로 저장, 저장 성공 후 미저장 해제 및 최종 파일의 부모가 지정 폴더와 정확히 같은지 검사한다. 결과 JSON의 flatOutputVerified/unsavedExitVerified/saveFlowVerified를 확인한다.
- 영상의 실제 160×120 크기, 일시정지·이동 후 빨강/파랑/빨강 표본 100%, 오디오 0개를 별도로 분석한다.
- 코어의 새 파일·대상 충돌·동의 후 교체·실패 시 원본 보존 검사와 무음 편집 회귀 검사를 유지한다.

실제 Mac 캡처·권한 시험은 별도이며 CI 빌드/자동 검사와 구분한다. 시스템 강제 종료나 프로세스 강제 중단은 일반 창 닫기의 확인 흐름과 별개다.
