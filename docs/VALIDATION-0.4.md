# 0.4.0-alpha.1 검증 — 2026-10-28

Windows11 build26200, Qt6.8.3, MSVC19.38, FFmpeg9.0.2. 이 변경의 검사는 모두 무음으로 수행했다.

## 자동 검사

Windows 로컬 CTest 10개: core, qml_smoke, qml_expanded, qml_custom, qml_small, qml_audio, qml_audio_expanded, source_discovery, settings_migration, encoder_preflight.

- 실제 장치·앱 이름을 넣은 UI fixture에서 마이크/컴퓨터 선택기의 이름과 두 믹서 탭을 확인한다. 음소거해도 선택 장치 이름이 유지된다. fixture는 실제 장치 기본값이나 가짜 입력 레벨을 생성하지 않는다.
- 기본/확장/720×640 창을 렌더하고 작은 창에서도 녹화와 저장 위치 버튼이 화면 밖으로 잘리지 않는지 검사한다.
- 도움말의 단축키, 라이선스, 앱 정보 액션이 실제 팝업을 연다. 내장 MIT 고지와 NAVER/OFL 원문도 확인한다.
- source_discovery는 제어된 플랫폼 목록을 자동 갱신한다. 동일 목록은 모델 알림을 다시 보내지 않고, 앱 추가 뒤 기존 마이크 선택과 45% gain을 유지하며, 제거된 마이크는 목록에서 사라진다. 장치 조회는 작업 스레드로 수행한다.
- CPU 인코더 검사는 실제 FFmpeg 3프레임 인코딩이며 소리를 출력하지 않는다.

마지막 선택기 검사는 팝업을 실제로 연 뒤 마이크 추가/해제와 시스템 전체/앱별 소리의 상호 배타 선택을 실행한다. 초기 검사에서는 Repeater 항목을 QObject 소유 트리에서 찾으려 해 종료43으로 실패했다. Qt의 시각 트리에서 팝업 항목을 찾도록 검사 코드를 수정한 뒤 로컬 10개가 모두 통과했다.

## 실제 Windows 경로

`tools/test-windows-region.ps1`은 자체 빨강/파랑 창만 녹화한다. 마이크나 다른 앱 화면을 캡처하지 않고 테스트 톤도 재생하지 않는다. OS 전역 단축키 등록을 확인한 뒤 앱 자신의 네이티브 스레드에 WM_HOTKEY를 전달해 시작, 일시정지, 재개, 종료를 검사했다. 물리 키 입력 시험과는 구분한다.

도움말이 열린 상태에서도 녹화 시작 시 팝업이 닫히고 400×104 최적 모드로 전환됐다. 실제 QML 테두리를 드래그해 녹화/일시정지 중 이동했고 160×120 출력의 0.3초/1.0초/1.8초 표본 프레임은 각각 100% 빨강/파랑/빨강이었다. 오디오 트랙은 0개다.

오디오 없는 자체 파일로 편집기 새 파일/덮어쓰기 버튼 경로도 검사했다. 0.5–2.5초 내보내기는 두 경우 모두 2.0초였고 새 파일 저장은 원본 SHA256을 유지했다. 덮어쓰기는 별도 테스트 복사본에만 수행했다. 기존 0.3의 3오디오 트랙 보존 결과와 구분한다.

## 시각 점검

기본/상세 패널, 메뉴, 마이크/컴퓨터 소리 팝업, 단축키/라이선스/앱 정보, 최소 크기 창을 렌더해 확인했다. 상단 메뉴는 창 버튼과 같은 줄이며 상세 패널 아이콘은 그 아래 창 오른쪽 끝에 있다. 홈의 단축키·인코더 설명·중복 경로와 새로고침 버튼은 제거됐다. 체크박스·슬라이더·팝업도 중립 회색의 공통 스타일을 사용한다.

컴퓨터 사용 도구로 실제 Windows 테스트 복사본을 열어 자동 장치 목록, 둥근 외곽, 통합 메뉴와 어두운 메뉴 선택 상태를 확인했다. 지원 환경에는 DWM의 다크 프레임·모서리·배경 소재를 요청하며 OS 설정/버전에 따른 표현 차이를 허용한다. 참고한 사용자의 원본 ChatGPT/Codex 이미지는 저장소에 올리지 않는다.

## 라이선스와 배포

직접 작성한 소스·문서·프로젝트 아트워크는 루트 LICENSE의 MIT로 공개한다. D2Coding은 원본 SIL OFL 1.1 및 NAVER 고지를 유지한다. Qt/FFmpeg는 각 기존 라이선스이며 MIT로 재라이선스하지 않는다. 앱 내 라이선스 화면, Qt 리소스, 배포 고지 파일에서 구분한다.

검증한 Windows ZIP은 압축을 새 폴더에 풀고 개발 Qt PATH 없이 무음 UI 검사로 실행한다. CI는 Windows/macOS 빌드·자동 검사·배포를 확인한다. 물리 Mac의 캡처·마이크·단축키·배경 효과 및 실제 장치 연결/해제 조합, 혼합 DPI와 장시간 녹화는 별도 인수 검증 대상으로 남긴다.
